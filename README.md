# Centro Informático Regional

Sitio web oficial de **Centro Informático Regional (CIR)**, empresa formoseña fundada en **1997**, dedicada a brindar soluciones en tecnología, informática, muebles, electrodomésticos, equipamiento comercial y servicio técnico.

La plataforma fue desarrollada para centralizar el catálogo de productos de la empresa, mejorar su presencia digital y facilitar el contacto entre los clientes y CIR.

## 🏢 Sobre CIR

**Centro Informático Regional** nació en 1997 como un emprendimiento orientado a la capacitación informática y, con el paso de los años, evolucionó hasta convertirse en una empresa multirubro con presencia regional.

Actualmente trabaja con una amplia variedad de marcas y productos destinados a hogares, oficinas, comercios y empresas.

## 🌐 Sobre el proyecto

La plataforma web de CIR fue diseñada para ofrecer una experiencia moderna, clara y adaptable a distintos dispositivos.

El sistema permite administrar el contenido del sitio desde un panel administrativo y mantener actualizado el catálogo comercial sin necesidad de modificar directamente el código.

### Funcionalidades principales

- Catálogo dinámico de productos
- Organización mediante rubros, categorías y subcategorías
- Página individual para cada producto
- Buscador de productos
- Productos destacados y recomendados
- Gestión de imágenes
- Información institucional de la empresa
- Sección de Servicio Técnico
- Integración con WhatsApp
- Formulario y medios de contacto
- Panel administrativo
- Gestión de productos desde administración
- Gestión de categorías y contenido
- Generación de presupuestos
- Incorporación de productos del catálogo a presupuestos
- Generación de presupuestos en PDF
- Presupuestos preparados para compartir con clientes mediante WhatsApp
- Diseño responsive para escritorio, tablet y dispositivos móviles

## 🏗️ Arquitectura

La aplicación separa las responsabilidades principales entre:

**Laravel**  
Gestiona la lógica de negocio, persistencia de datos, autenticación, administración y operaciones del backend.

**React**  
Construye las interfaces dinámicas e interactivas utilizadas por los usuarios.

**Tailwind CSS**  
Permite desarrollar una interfaz responsive y mantener un sistema visual consistente.

**MySQL**  
Almacena la información relacionada con productos, categorías, usuarios, presupuestos y demás entidades del sistema.

## 📦 Catálogo

El catálogo constituye uno de los módulos principales de la plataforma.

Los productos se organizan jerárquicamente para facilitar su navegación:

```text
Catálogo
│
├── Informática
│   ├── Computadoras
│   ├── Notebooks
│   ├── Monitores
│   ├── Gaming
│   ├── Periféricos
│   ├── Componentes y Hardware
│   ├── Redes
│   └── Impresión
│
├── Muebles
│   ├── Oficina
│   └── Hogar
│
├── Línea Comercial
│   ├── Frío Comercial
│   ├── Calor Industrial
│   ├── Amoblamiento Comercial
│   └── Varios
│
└── Electrodomésticos
```

Cada producto puede disponer de información como:

- Nombre
- Descripción
- Imágenes
- Categoría
- Subcategoría
- Características
- Estado
- Etiquetas
- Información comercial

## 🧾 Sistema de presupuestos

El panel administrativo incorpora un módulo destinado a generar presupuestos para clientes.

Permite seleccionar productos existentes dentro del catálogo y generar una propuesta comercial con información organizada y presentación profesional.

Entre sus funcionalidades se encuentran:

- Selección de productos del catálogo
- Visualización de imágenes
- Información del cliente
- Cantidades y valores
- Generación del presupuesto
- Exportación a PDF
- Presentación corporativa de CIR
- Preparación para envío mediante WhatsApp

---

## 🔐 Panel administrativo

El sistema cuenta con un área administrativa destinada a gestionar el contenido de la plataforma.

Desde este entorno se pueden administrar diferentes elementos sin necesidad de modificar directamente el código fuente.

```text
Administración
├── Productos
├── Categorías
├── Imágenes
├── Contenido
├── Presupuestos
└── Configuración
```

## 📱 Diseño responsive

La interfaz está diseñada siguiendo un enfoque responsive, adaptándose a:

- 🖥️ Computadoras
- 💻 Notebooks

## 🚀 Objetivo del proyecto

El proyecto busca transformar la presencia digital de **Centro Informático Regional** mediante una plataforma que permita:

- Centralizar el catálogo comercial.
- Modernizar la presentación de los productos.
- Facilitar la búsqueda de productos y categorías.
- Mejorar la comunicación con potenciales clientes.
- Digitalizar procesos comerciales.
- Simplificar la generación de presupuestos.
- Facilitar la administración del sitio.
- Construir una base escalable para futuras funcionalidades.
